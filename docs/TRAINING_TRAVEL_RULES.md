# 교육훈련 출장 계산 규칙

교육훈련의 숙박 여부는 주소만으로 자동 판정하지 않고 사용자가 선택한다.

## 숙박 형태

- `non_lodging` 비숙박(매일 귀가): 숙박 0박, 왕복 횟수 = 출장일수
- `full_lodging` 전일 숙박: 숙박 박수 = 출장일수 - 1, 왕복 횟수 = 1
- `mixed` 혼합: 숙박 박수를 직접 입력, 왕복 횟수 = 출장일수 - 숙박 박수

예: 3일 교육훈련

- 0박 → 왕복 3회
- 1박 → 왕복 2회
- 2박 → 왕복 1회

## 일비

등록일·수료일은 전액, 기타일은 비숙박 적용일 50%, 숙박 적용일 미지급으로 계산한다. 혼합형은 중간일 중 비숙박 적용일 수를 사용자가 직접 지정한다. 공용차량 이용 시 산정된 일비의 50%를 감액한다.

## 식비

- 전일 숙박: 교육훈련기관 청구액 입력
- 비숙박: 근무지내/외 기준표 적용
- 혼합: 자동추정하지 않고 교육훈련기관 청구액을 직접 적용한다.

## 운임

근무지내 교육훈련은 기준표에 따라 운임 미지급으로 처리한다. 근무지외 자동차운임은 위 숙박 형태에 따른 총 이동거리를 기준으로 계산한다.
